1. 请将压缩包中的整个“洛奇播报小助手”文件夹解压到一个独立目录。不要把“洛奇播报小助手.exe”和“程序文件”直接散放在桌面、文档或下载目录中。
2. 目前暂时只支持亚特服务器！
3. 如果使用UU加速器，请切换至路由模式
4. 未使用过Micopunch的用户，请先安装Npcap 1.87（本插件包中有附带）；已用过Micopunch的用户可以跳过此步骤，直接启动
5. 如需同时使用Micopunch，请先启动本工具，再启动Micopunch，否则可能会发生冲突
6. 请双击洛奇播报小助手.exe启动（需要管理员权限哦）
7. 如果遇到BUG，请联系我修复哦（亚特：无染渊）
8. 报告上报BUG的时候，请尽量提供对应场次的整个日志文件夹。日志位于“洛奇播报小助手\程序文件\BuffWatcher\logs\日期-启动日志”处。
